# Práctica 1 - Flujo Básico de git y github
1.¿Qué es una Base de Datos Relacional?
Es un sistema que permite guardar y organizar información en tablas que se relacionan entre sí, facilitando la consulta y administración de los datos.

2.¿Qué es una Tabla en el contexto de Bases de Datos Relacionales?
Es la estructura donde se almacenan los datos dentro de la base de datos, organizada en filas y columnas.

3.¿Qué es una relación en Bases de Datos Relacionales?
Es la conexión entre dos o más tablas mediante un campo en común que permite relacionar la información.

4.¿Qué representa una columna?
Una columna representa una característica o atributo de los datos, como nombre, edad o dirección.

5.¿Qué representa un renglón?
Un renglón o fila representa un registro completo dentro de la tabla.

6.¿Qué es un motor de base de datos relacional?
Es el software que administra la base de datos, permitiendo crear, consultar y modificar los datos.

7.¿Cuáles son los motores más populares?
Algunos de los más usados son MySQL, PostgreSQL, Oracle, SQL Server y MariaDB.

8.¿Qué motor es ligero y no necesita servidor?
SQLite, porque funciona directamente dentro de la aplicación.
